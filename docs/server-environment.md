# サーバー構成と切り替え計画

## 初期ドメインでの並行作業

XServerの初期ドメイン `xs885095.xsrv.jp` の公開領域を次のように分離する。

| URL | FTP上の配置先 | 用途 |
| --- | --- | --- |
| `/current/` | `xs885095.xsrv.jp/public_html/current/` | 現行サイトの移行確認 |
| `/cms/` | `xs885095.xsrv.jp/public_html/cms/` | リニューアルサイトのWordPress |

デザイン2案は `/cms/design-a/` と `/cms/design-b/` の固定ページとして作成する。1つのテーマ内にA案・B案それぞれのページテンプレートを用意し、採用案をそのまま本番実装へ発展させる。

## 現行サイトの独自ドメイン切り替え

1. 現行サイトを `/current/` で確認する
2. XServerに独自ドメインを追加する
3. 自動生成された `独自ドメイン/public_html/` へ現行サイトのファイルをコピーする
4. DB内URL、`wp-config.php`、SSL、フォーム送信などを確認する
5. DNS切り替え後も、初期ドメインの `/cms/` でリニューアルサイトの構築を継続する

「移動」ではなく、動作確認が終わるまでは「コピー」とする。独自ドメイン側の正常稼働を確認してから `/current/` を整理する。

## WordPress環境

- WordPressは初期ドメインの `/cms/` にインストールする
- DBはリニューアルサイト専用とし、現行サイト用DBと分離する
- 初期ドメインの無料SSLを有効化する
- 検索エンジンのインデックスを無効化し、サーバーのアクセス制限も設定する
- WordPress、FTP、DBの認証情報はGitに含めない

## Gitとの対応

| Gitブランチ | 対応先 |
| --- | --- |
| `origin` | 現行サイトデータ |
| `test` | 初期ドメインの `/cms/` |
| `main` | リニューアル後の本番サイト |
