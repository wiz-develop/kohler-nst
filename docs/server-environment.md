# サーバー構成と切り替え計画

## 初期ドメインでの並行作業

XServerの初期ドメイン `xs885095.xsrv.jp` の公開領域を次のように分離する。

| URL | FTP上の配置先 | 用途 |
| --- | --- | --- |
| `/current/` | `xs885095.xsrv.jp/public_html/current/` | 現行サイトの移行確認 |
| `/renewal/` | `xs885095.xsrv.jp/public_html/renewal/` | リニューアルサイトの構築・確認 |

デザイン2案は、WordPress導入前は `/renewal/sample-a/` と `/renewal/sample-b/` の静的ページとして案内できる。採用案の決定後にWordPressテーマへ組み込む。

## 現行サイトの独自ドメイン切り替え

1. 現行サイトを `/current/` で確認する
2. XServerに独自ドメインを追加する
3. 自動生成された `独自ドメイン/public_html/` へ現行サイトのファイルをコピーする
4. DB内URL、`wp-config.php`、SSL、フォーム送信などを確認する
5. DNS切り替え後も、初期ドメインの `/renewal/` でリニューアルサイトの構築を継続する

「移動」ではなく、動作確認が終わるまでは「コピー」とする。独自ドメイン側の正常稼働を確認してから `/current/` を整理する。

## WordPress導入前の必須作業

- 初期ドメインの無料SSLを有効化する
- サーバーパネルの「WordPress簡単インストール」で `/renewal/` にインストールする
- DBは簡単インストールで自動作成するか、専用DBとDBユーザーを事前に作成する
- 検索エンジンのインデックスを無効化し、サーバーのアクセス制限も設定する
- WordPress、FTP、DBの認証情報はGitに含めない

## Gitとの対応

| Gitブランチ | 対応先 |
| --- | --- |
| `origin` | 現行サイトデータ |
| `test` | 初期ドメインの `/renewal/` |
| `main` | リニューアル後の本番サイト |
