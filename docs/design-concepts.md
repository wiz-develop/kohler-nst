# デザイン案 A / B

## 共通のコンテンツ構成

`NSTM_サイトリニューアル方針_20260731.pdf` 7ページに基づき、両案とも次の9セクションで構成する。

1. ヒーロー（検査・通水風景）
2. 4つの不安と4つの回答
3. 品質を示す数字
4. 国内ラボの通水検証
5. 品質の約束とプロジェクトサポート
6. プロジェクト対応
7. KOHLER公式の商品情報・カタログ・ショールームへの導線
8. 日鉄グループと検査の文化
9. 用途別のお問い合わせ

## A案：ダーク・フォトグラフィック

- 核心：「暗所で行われる検査の記録」
- 色：ブラック `#080a0b`、鋼 `#78868b`、水 `#316979`、白 `#ffffff`
- 写真：検査対象と水流だけに光を当てる
- 特徴：不安、検査体制、納入までの工程を写真の連続で見せ、品質を視覚的に証明する
- 構成：4つの不安を写真カードで提示し、数字と検査写真、5工程、2つの支援領域へ続ける

## B案：ライト・ジャーナル

- 核心：「工程を追って理解できる品質記録」
- 色：ペーパー `#fafafa`、インク `#111518`、薄鋼 `#dfe6e7`、深水 `#234f5e`
- 写真：白い検査室と作業者の手元を明るく見せる
- 特徴：説明と支援内容を先に整理し、初めての読者でも情報の順番を追える
- 構成：役割説明と4つの支援領域、プロジェクト対応、5工程、品質・案件支援の順に読む

## WordPress

- B案：`/cms/design-b/`

## 掲載情報の扱い

- 本文、数値、リンクは公開を前提とし、会社・ブランドの公式情報で確認できる内容を掲載する
- 未確認の検品数や在庫品番数、架空の案件名・規模は掲載しない
- 生成画像には「写真はイメージです」と表示し、撮影素材の用意ができた段階で差し替える
- A案とB案は同じ原稿を使用し、デザインのみを比較できる状態にする
