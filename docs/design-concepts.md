# デザインサンプル A / B

## 共通のコンテンツ構成

`NSTM_サイトリニューアル方針_20260731.pdf` 7ページに基づき、両案とも次の9セクションで構成する。

1. ヒーロー（検査・通水風景）
2. 4つの不安と4つの回答
3. 品質を示す数字
4. 国内ラボの通水検証
5. 品質の約束とプロジェクトサポート
6. 納入実績
7. KOHLER公式の商品情報・カタログ・ショールームへの導線
8. 日鉄グループと検査の文化
9. 用途別のお問い合わせ

## A案：ダーク・フォトグラフィック

- 核心：「暗所で行われる検査の記録」
- 色：ブラック `#080a0b`、鋼 `#78868b`、水 `#316979`、白 `#ffffff`
- 写真：検査対象と水流だけに光を当てる
- 特徴：ひとつの強いヒーロー写真を記憶点にし、他の要素は静かに整理する

## B案：ライト・ジャーナル

- 核心：「工程を追って理解できる品質記録」
- 色：ペーパー `#fafafa`、インク `#111518`、薄鋼 `#dfe6e7`、深水 `#234f5e`
- 写真：白い検査室と作業者の手元を明るく見せる
- 特徴：罫線と左揃えで、初めての読者でも情報の順番を追える

## WordPress

- A案：`/cms/design-a/`
- B案：`/cms/design-b/`
- テーマ：`wp-content/themes/nstm-concepts/`
- 固定ページは `NSTM Design A` / `NSTM Design B` テンプレートを使用する
- 検索エンジンのインデックは無効化する

## 公開前に差し替える項目

- 年間検品点数、検査項目数、取扱年数、拠点数、在庫品番数
- 実際の納入実績、規模、説明文
- 撮影済みの検査・ラボ・納入案件写真
- お問い合わせフォームのURL
- KOHLER公式サイトの個別ページURL
